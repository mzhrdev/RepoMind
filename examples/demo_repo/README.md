# Demo Repo

A tiny synthetic repository used to demonstrate RepoMind without needing an
external codebase.

- `calculator.py` implements basic arithmetic with a `CalculatorError`.
- `inventory.py` implements an in-memory inventory that reuses `CalculatorError`.

Try asking RepoMind:

- "How does the calculator handle division by zero?"
- "What happens when I remove more stock than exists in the inventory?"
- "How does apply_operation dispatch operations?"
